Arc Lake Help

A quick reference while things are still actively evolving — this page will grow as the app does.

◈ Signing In

GitHub sign-in is the supported way to sign in right now, and it fully backs up your work — see Saving & Backup below.

Temporarily Hidden Sign in with Apple is turned off for the moment while we sort out a platform-level issue that isn't specific to your device or account. It'll come back once that's resolved — nothing about your work depends on it in the meantime.

You can also use Continue as Guest to try the app without signing in, though your work won't be backed up in guest mode.

◈ Saving & Backup

Your project data automatically backs up to iCloud Drive, in the Autumn-Ash/ArcLake folder — independent of which sign-in method you use. As long as iCloud is signed in on your device, your work is being saved there.

If you ever want to check it directly: open the Files app → iCloud Drive → Autumn-Ash → ArcLake.

◈ Atoms & Physics

The Atoms tab is where you build your active element set — open the Periodic Table to add elements to the current scene. The header there also has a batch menu (stacked-squares icon) with Add First Half, Add Second Half, and Add All Elements, so populating a large scene doesn't mean tapping every element one at a time.

Every placed atom is rendered as a real particle cloud, not a placeholder: neutrons and protons each get one particle (they only supply the neutron-first propagation math), while each individual electron gets its own cluster of particles sampled from its actual quantum orbital — not just scattered points. Both the particle count per electron and the pixel size of every particle (electrons and nucleons separately) are adjustable from the Particle Rendering card in the Algebra tab.

The Physics tab controls the scene's environment — gravity, pressure, temperature, and related simulation settings that every placed atom reacts to.

Placement itself is physics-aware: atoms spread across real 3D space (not a flat plane), and packing tightens as more atoms/molecules accumulate in a scene, on top of whatever the environment's own pressure setting does.

◈ Algebra Menu

The Algebra tab (the f(x) icon, between Atoms and Physics) is where you build Equation Nodes. For each node you pick a role — Neutron (origin), Proton (resolves Gas/Liquid/Solid state via angle/degree congruency), Algebra (propagates outward once Proton has resolved), or Group (an outer-parentheses container with no math of its own, just a shared visual boundary and label for other nodes nested inside it) — then bind it to an element currently in the scene, and add sockets with the +/- controls: Element, Component, Orbit Shell, Math Operator, Bond, and Delta. Orbit Shell and Math Operator use real pickers (K/L/M/N/O/P/Q and +/−/×/÷), not free text.

Every node also shows its six real physics values for the bound element — mass, volume, weight, density, temperature, and velocity — computed from the element's actual atomic mass/density plus the current environment (Earth-standard by default), not placeholder numbers.

Tap Build Equation Node and it's immediately added to the shared graph and opens the Node Editor so you can see it land there and start wiring curve connections between sockets.

One node = one element. To connect a second (or third) atom into the same equation, build a separate node for it and wire a curve between the two nodes' sockets in the Node Editor — that's how a bond or delta between two atoms gets represented.

◈ Node Editor

Open the Node Editor from the profile panel (or automatically when you build a node) to see every equation node in one shared graph — no separate mode or toggle, they're always there alongside the app's other node types. Drag a node to reposition it; connected curves track it live, even mid-drag.

Each node card has a small duplicate icon (two overlapping squares) that copies its role, element binding, group, and sockets to a new independent node nearby, ready for its own connections — handy for building several similar equations without starting from scratch each time.

Nodes nested inside a Group node are shown with a dashed orange boundary and the group's label, so a set of related equations reads as one visual unit.

◈ Molecule Canvas

Place atoms, set a bond order (single/double/triple), and toggle Delta mode to wire orbit-shell connections between atoms. Anything wired here shows up as the matching equation node connections in the Algebra Menu and Node Editor too — it's the same underlying data everywhere, not a separate copy.

◈ Arc Edge Field Array

Use Select All / Deselect All in the element list to quickly link every atom in the scene for Arc Edge connections, instead of tapping each one individually. Tap order still matters for anything sequence-sensitive — Select All just appends everything not yet selected in list order.

◈ Themes

Tap the palette icon in the header to cycle through the available color themes — your choice is remembered between sessions.

◈ Something Not Working?

Arc Lake is under active, fast-moving development — if something looks off, it's likely already known and being worked on. This help page will be kept up to date as things change.
