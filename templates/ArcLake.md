# Release Notes

## Current Release: Web App Beta v1.2.b
* **New Orbit Delta Node Editor and CFD Scene Node Editor (Replaces CFD setings menu)**
    * Toggle on the orbit Delta from the main menu pan all the second icon from top left then select elements that have been added to the node canvas and then the element should highlight white instead of yellow then when done selecting tap elsewhere to apply the Orbit Delta. When the Orbit Delta has been applied the icons will propagate additional Delta icons next to that element, at this point you can select that Delta icon and open up the Orbit Delta Node Editor. The Orbit Delta Nodes have incoming and outgoing sockets for that elements available orbit shells. The CFD, (LSCFD - Large Scale Computational Fluid Dynamics), node editor replaces the CFD settings menu allowing for each atomic tab scene editor to support incoming and outgoing environment connections as well as the six orders of math operations in the six orders of physics operations as well there's a node for the Arc Measure Tool
