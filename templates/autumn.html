Welcome to Autumn

Autumn stores conversation history and memory locally on your device using browser storage. This allows her to remember your conversations across sessions. No data is sent to external servers beyond the AI response API.

If you ever clear your browser storage, you can export your data first as a backup file.

◈ IDE ACCESS

Enter your IDE password to access the Autumn logic editor and Claude update pipeline.

◈ GITHUB TOKEN

A GitHub Personal Access Token (PAT) with repo → contents write access is required to read and write templates/autumn-logic.js.

Get one at github.com/settings/tokens → Generate new token (classic) → check repo.

Your token is stored in sessionStorage only and cleared automatically when you close this tab.

◈ ANTHROPIC API KEY

An Anthropic API key is required so the IDE can call Claude to generate logic updates.

Get one at console.anthropic.com/settings/keys.

Your key is stored in sessionStorage only — cleared automatically when you close this tab. It is never committed to GitHub or sent anywhere except Anthropic's API.
