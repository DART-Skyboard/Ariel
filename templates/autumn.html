If you ever clear your browser storage, you can export your data first as a backup file.

◈ GITHUB TOKEN

A GitHub Personal Access Token (PAT) is needed to read and write autumn-logic.js.

To get your PAT:
1. Go to github.com/settings/tokens
2. Click Generate new token (classic)
3. Set expiration, check repo → contents scope
4. Copy the token starting with ghp_

Your token is stored in sessionStorage only and cleared when you close the tab.
