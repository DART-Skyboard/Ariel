Arc Edge Measure

Impedance measurement · Smith chart · 3D point-cloud visualization

Overview

Arc Edge Measure is an RF impedance-matching tool built around the classic Smith chart, with a second, fully 3D point-cloud visualization of the same data layered underneath it. Everything you set on one side — load impedance, frequency, presets — drives both views at once.

The top-left button on the chart toggles between the two:

  • 2D the flat Smith chart, with live wave animations and a full readout panel
  • tap it again for the 3D point-cloud scene — a spherical version of the same chart you can orbit, drag a gimbal through, and take measurements in

The right-hand side panel (Load Impedance, presets, chart toggles) stays visible and live in both modes, so you can keep adjusting inputs while looking at either view.

Load Impedance & Presets

The core inputs, top of the right panel:

FieldMeaning
RLoad resistance, in ohms
jXLoad reactance, in ohms (negative = capacitive, positive = inductive)
Z₀Characteristic/reference impedance of the line, usually 50Ω
FrequencyDrives the animation speed of the wave visualizations — doesn't change the impedance math itself, but does change how the waves render and how the 3D wave tubes animate

The RF / Antenna Presets row above them fills in R and jX for common cases — 50Ω/75Ω match, open/short circuit, dipole, λ/4 monopole, and a few example mismatch/reactance scenarios — as a quick way to see what a given condition looks like on the chart without typing numbers.

On the 2D chart, you can also just drag the match point (the glowing dot) directly — it updates R/jX live as you move it, anywhere inside the outer circle.

The 2D Smith Chart

The standard Smith chart: constant-resistance circles, constant-reactance arcs, and the match point. Behind it, two animated wave-field layers can be toggled independently under Chart Underlay — Large Canvas:

  • Radial Wave Field — a full-disc interference pattern showing incident/reflected wave peaks and nulls radiating from the center
  • Left-Right Wave Strip — a horizontal standing-wave strip across the chart

Both can be on at once — they composite together rather than replacing each other.

Mic / Audio Reactive

The Mic Input toggle (under Audio Reactive) lets your microphone drive the wave amplitude in both the 2D and 3D views at once — louder input pushes the waves harder, in real time.

Tapping it on will prompt for microphone permission. A small level meter appears under the toggle once it's active. Turning it off fully releases the microphone rather than just muting it.

On iPhone, using the mic here may pause background audio from other apps (Spotify, YouTube Music, etc.) — this is an iOS system behavior for any website using the microphone, not something this page can control. There's no browser-level setting that changes it; it would only be avoidable in a native app, not a website.

Reading the Output

ReadoutMeaning
Reflection ΓMagnitude of the reflection coefficient, 0 (perfect match) to 1 (total reflection)
Angle ∠ΓPhase angle of the reflection coefficient
VSWRVoltage Standing Wave Ratio — 1.00:1 is a perfect match, higher is worse
Return LossHow much power is reflected back, in dB — higher is better (∞ dB at a perfect match)
Mismatch LossPower lost to the mismatch itself, in dB
Q FactorSharpness of the resonance implied by the current R/jX
Arc-Edge Doc CircumferenceA custom measurement convention: c = d × 3 (not π) — see below

The Arc-Edge "doc circumference" is deliberately not the standard c = πd. It treats |Γ| as a working diameter fraction and multiplies by exactly 3, matching the same convention used by the Blender Arc Edge measurement tool this project is named after. It's a bridge between chart position and a doc-based arc output, not a physical circumference.

The 3D Point Cloud Scene

Tap the 3D button to switch. The flat chart becomes a full spherical point cloud: a shell of six axis-offset spheres plus three orthogonal outer great-spheres (mimicking a 3D/spherical Smith chart), with nine glowing wave tubes — incident, reflected, and standing, one of each along each axis — animating through it.

Camera

  • Drag empty space to orbit
  • Pinch (touch) or scroll (mouse) to zoom

The green gimbal

This is the same match point as the 2D chart's dot, just in 3D. Drag it anywhere — including all the way out to the boundary of the outer sphere — and it updates R/jX live, exactly like dragging the point on the 2D chart does. Watch the reflected and standing wave tubes especially: their amplitude directly tracks how far off-center (mismatched) the gimbal is.

The 3D scene requires WebGPU. If your browser or device doesn't support it, you'll see a message explaining why instead of a blank screen — try a recent Chrome, Edge, or Safari 18+.

Point Cloud Settings

The ⚙ POINTS button (bottom HUD, in 3D mode) opens a panel with independent controls for each part of the point cloud:

GroupControls
Smith Chart ShellPoint count (default 1000) and size, in real screen pixels (1–20px)
Points Per CurveShared count applied to all 9 wave tubes at once (default 300 each)
Incident / Reflected / Standing CurvesIndependent glow toggle + size for each wave type
Arc Edge / Shape CurveGlow + size for the triangulation curve (see below); its point count isn't independently set — it automatically tracks the Points Per Curve setting above

Every size slider is calibrated to actual screen pixels — "1px" means roughly one pixel on screen regardless of how far you've zoomed the camera, up to a ceiling of 20px.

Measurements

In 3D mode, position the green gimbal somewhere and tap + ADD MEASUREMENT to drop a blue marker there. Repeat for as many as you want (up to 12).

  • Each marker is draggable directly in the scene — tap and drag it like the gimbal
  • Every marker also gets a card in the Triangulation panel with editable X / Y / Z number fields for exact positioning, and a ✕ to remove it
  • Markers are labeled M1, M2, M3… in the order they were added, and relabel automatically if one is removed

Triangulation & the Curve Tool

With 2 or more measurements placed, tap TRIANGULATE to get pairwise distances and arc-edge doc-circumference values between them, in the order they were added.

Close Loop

Connects the last measurement back to the first, closing the sequential chain into a loop.

Curve Tool

For connecting specific markers directly to the green gimbal — not just the sequential chain:

  1. Toggle CURVE TOOL on
  2. Tap the blue markers you want to include — each one highlights yellow when selected; tap again to deselect it
  3. Tap the green gimbal to finalize — this draws a spoke from every selected marker straight to the gimbal, and turns the tool off automatically
  4. Toggle it back on any time to build another, separate group of spokes to a different set of markers

All of this — the sequential chain, Close Loop, and every curve-tool group — is drawn live as a single glowing yellow curve, and updates continuously as you drag any marker or the gimbal, not just when you tap Triangulate.

CLEAR CURVES removes only the curve-tool groups, leaving your measurement points in place. The plain CLEAR button removes everything — measurements, curves, and the selection.

Physics & Indicators

  • Physics Reaction — when on, the wave-tube particles pick up simple gravity and atmospheric damping, plus a disturbance impulse radiating from each measurement point, instead of following a pure kinematic sine path
  • Indicators — toggles the floating text labels (gimbal readout, measurement labels) on or off

Exporting

  • PNG 2K / 3K / 4K — renders the current 3D view to a transparent PNG at that resolution and downloads it
  • EXPORT GLB — exports the entire current point cloud (chart shell, wave tubes, gimbal, measurements) as a .glb file, downloaded automatically. Every point is exported as a small real triangle (not a raw "point primitive"), so the file opens correctly in Nomad Sculpt, Blender, or any standard 3D tool — not just specialized point-cloud viewers.

GLB export is a snapshot of the scene at the moment you export it — it captures the current wave positions, not the live animation itself.

Troubleshooting

3D scene won't load / shows a message instead of the chart

Your browser doesn't support WebGPU, or your device's GPU couldn't be accessed (hardware acceleration may be disabled). Try a recent Chrome, Edge, or Safari 18+, and check that hardware acceleration is enabled in your browser's settings.

Mic toggle doesn't do anything / no sound reaction

Check that microphone permission was actually granted — if it was denied, a status message appears under the toggle explaining that, and you'll need to allow it in your browser or site settings before trying again.

The chart or wave field looks stretched/oval

This has come up on some viewport sizes in the past and been fixed each time it was reported — if you see it, it's worth reporting, since it's not expected behavior.

I don't lose my measurements/gimbal position by coming here, right?

Correct — this help page opens in its own new tab. Nothing here touches the app page's memory, so switching back to that tab (or tapping "Close Help" above, or just closing this tab yourself) leaves your measurements, curve groups, and settings exactly as you left them. Note that none of that is saved to a file automatically, though — closing or reloading the app tab itself will still reset it, same as before.
